# 다음 장 프론트엔드

오늘의 할 일과 일기를 기록하고, 내일의 계획을 위한 대화 영역을 보여주는 정적 프론트엔드입니다.

## 현재 구현 범위

- 반응형 다이어리 화면
- 오늘 할 일 추가, 완료, 삭제
- 일기 입력 및 글자 수 표시
- 일기와 대화 입력란의 한국어 마이크 음성 입력
- 일기 입력 검증과 프론트엔드 완료 상태 표시
- Cloud Run 백엔드로 일기와 오늘 할 일 전송
- Firestore 저장 성공·실패 상태 표시와 중복 제출 방지
- 저장된 일기를 기준으로 천사·악마·진행자와 내일 계획 대화
- 확정된 내일 계획을 다이어리 오른쪽 페이지에 표시
- 키보드 포커스, 스크린 리더 안내, 모션 감소 설정 지원

## 아직 구현하지 않은 범위

- 이메일 발송

일기, 오늘 할 일, 대화 및 확정된 내일 계획은 백엔드를 통해 Firestore에 저장됩니다. 브라우저 화면의 입력 상태 자체는 새로고침하면 초기화됩니다.

음성 입력은 브라우저의 Web Speech API를 사용합니다. 사용자가 마이크 버튼을 눌렀을 때만 시작하며 앱은 음성 파일을 저장하지 않습니다. 브라우저에 따라 음성이 브라우저 제공자의 서버 기반 인식 서비스에서 처리될 수 있고, 지원되지 않는 브라우저에서는 마이크 버튼이 비활성화됩니다.

## 환경 변수와 빌드

Netlify 프로젝트 환경변수에 Cloud Run 서비스의 공개 HTTPS Origin을 설정합니다.

```dotenv
API_BASE_URL=https://replace-with-cloud-run-service-url
```

Netlify는 `netlify.toml`에 따라 다음 명령으로 `dist/`를 생성합니다.

```powershell
npm run build
```

## 로컬 실행

로컬 `.env`의 `API_BASE_URL`을 사용해 빌드한 다음 `dist/`를 실행합니다.

```powershell
npm run build:local
python -m http.server 4173 --directory dist
```

그런 다음 브라우저에서 `http://localhost:4173`을 엽니다.
